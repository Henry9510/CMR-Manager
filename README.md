# CMR – Control de Mantenimiento y Confiabilidad

CMR es una aplicación de **gestión de mantenimiento (CMMS)** diseñada para centralizar, organizar y optimizar las actividades de mantenimiento industrial, permitiendo un mejor control de activos, órdenes de trabajo, inventarios y confiabilidad operacional.

---

## 🚀 Características principales

* 📋 Gestión de órdenes de trabajo (OT)
* 🏭 Administración de activos y equipos
* 🔧 Mantenimiento preventivo y correctivo
* 📦 Control de repuestos e inventario
* ⏱️ Registro de tiempos de trabajo
* 📊 Indicadores de mantenimiento (MTBF, MTTR, disponibilidad)
* 👥 Gestión de usuarios y roles
* 📈 Historial de mantenimiento por activo

---

## 🧠 Objetivo del proyecto

El objetivo de **CMR** es mejorar la **confiabilidad de los activos** y reducir paradas no planificadas mediante una correcta planificación, ejecución y análisis del mantenimiento.

Este proyecto puede ser utilizado como:

* Sistema académico
* MVP para empresa
* Módulo de mantenimiento integrado a un ERP

---

## 🏗️ Arquitectura general

* **Frontend:** HTML, CSS, JavaScript (Bootstrap)
* **Backend:** Java Spring Boot
* **Base de datos:** MySQL / PostgreSQL
* **Autenticación:** Roles y permisos
* **API:** REST

---

## 📂 Módulos del sistema

1. **Activos**

   * Registro de equipos
   * Ubicación y criticidad
   * Historial técnico

2. **Órdenes de trabajo**

   * Preventivas
   * Correctivas
   * Emergencias

3. **Mantenimiento preventivo**

   * Planificación por tiempo u horas
   * Calendario de tareas

4. **Inventario**

   * Repuestos
   * Entradas y salidas
   * Stock mínimo

5. **Indicadores (KPIs)**

   * MTBF
   * MTTR
   * Disponibilidad
   * Cumplimiento del plan

---

## 📊 Indicadores clave

* **MTBF (Mean Time Between Failures)**
* **MTTR (Mean Time To Repair)**
* **Disponibilidad operacional**
* **Backlog de mantenimiento**

---

## 🔐 Roles de usuario

* Administrador
* Planificador de mantenimiento
* Técnico
* Supervisor

## 🛠️ Instalación (ejemplo)

```bash

# Backend
cd backend
mvn spring-boot:run

# Frontend
cd frontend
npm install
npm run dev
```
